# FORMULOVE — зображення футболок

Дев’ять оригінальних фотореалістичні візуалізації, створені для демонстраційного каталогу. Це не фотографії виготовлених зразків і не підтвердження якості або фактичної наявності товару.

Файли `*.jpg.b64` — JPEG у текстовому Base64. Під час `npm run build` файли декодуються в `public/products/*-concept-v1.jpg`. Cloudflare публікує тільки папку public, без вихідного коду, ключів, D1 або файлів покупців.

Мокап показується в demo та у live-передзамовленнях із явним поясненням покупцю і тільки коли для товару ще не задано фото власника. Фото, завантажене власником командою `/photo heart` (так само lights/speed), має пріоритет. Для готових товарів вбудовані мокапи не підставляються. Чинні фото, каталог, замовлення й налаштування D1 не перезаписуються.

Показані кольори: heart — чорний, lights — молочний, speed — чорний. Інші кольори не сфотографовані. Оригінальні PNG збережені окремо в робочому просторі.
