# FORMULOVE — кабінет адміністратора в Telegram

Оновлено 19 жовтня 2026 року.

## Як відкрити

У своєму приватному чаті з ботом надішліть **/start** або **/admin**. Адміністратор одразу бачить власний кабінет із кнопками. Номер телефону для керування запитувати не потрібно.

Звичайні покупці отримують меню магазину. Прихована кнопка чи вручну сформований запит не дають доступу до керування: права перевіряються на сервері за Telegram ID. Чинні ADMIN_IDS у Cloudflare мають пріоритет над налаштуванням у базі. Нових адміністраторів це оновлення не додає.

Для вебкабінету потрібен SETUP_KEY. Посилання з бота не містить секретного ключа. Основні щоденні операції виконуються прямо в Telegram без ручного введення команд.

## Приклади

**Змінити ціну:** Товари → модель → Ціна → введіть суму → перевірте → Зберегти.

**Оновити фото:** Товари → модель → Фото товару → надішліть фото чи файл PNG/JPEG/WebP → Зберегти. Спеціальний підпис не потрібен. Аналогічно працює «Картинка розмірів».

**Змінити залишок:** Склад → модель → колір/розміри → нова вільна кількість → Зберегти. Значення −1 означає «під замовлення», 0 — «немає». Уводьте саме доступну до продажу кількість, без уже зарезервованих одиниць. Якщо залишок змінився під час редагування, бот попросить відкрити його заново.

**Додати нову модель:** Товари → схожа модель → Створити нову модель на цій основі → назва → ціна → Зберегти → До товару. Кольори, розміри, категорія та опис успадковуються. Копія прихована, без фото й замірів; усі її залишки — нуль. Відредагуйте опис, додайте власне зображення й потрібні залишки, потім натисніть «Показати». Для live товар має пройти перевірки готовності. Ліміт — 100 моделей.

**Додати ТТН:** Замовлення → потрібне → підтвердьте → Додати ТТН → 14 цифр. Покупець отримає сповіщення за наявною чергою.

**Витрата:** Фінанси → Додати витрату → категорія → сума → короткий опис → Зберегти. Витрата demo не входить до live-звіту.

**Повернення:** Відкрийте замовлення → Повернення коштів · запис → фактично повернута сума → Зберегти. Це обліковий запис, не банківський переказ. Для monobank використовується перевірка операції банку, щоб не дублювати її вручну.

**Зупинити розсилку:** Розсилки → потрібна → Зупинити розсилку → Зберегти. Наступні партії не відправляються; уже відправлене не відкликається.

## Захист від випадкових змін

- Зміни даних проходять через перегляд і кнопку збереження.
- Старе підтвердження не застосовується повторно після завершення або скасування.
- Редагування товару, залишку чи налаштувань не затирає вже змінені дані іншої операції.
- Стара відкрита вебпанель просить оновитися, якщо налаштування вже змінили через бот.
- Покупця не можна підписати на рекламу з адмінської картки: його власна згода зберігається окремо.
- Токени Telegram, monobank, ключі доступу й список адміністраторів не змінюються через звичайні поля чату.
- Запис оплати чи повернення відокремлено від статусу відправлення. Сума замовлень не є чистим прибутком.

Попередні товари, фото, замовлення, ціни та склад не очищаються. Саме встановлення оновлення не створює товарів, не змінює залишків і не надсилає розсилок покупцям.
